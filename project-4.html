Overview

GestureCanvas is a personal project I built to explore computer vision and real-time hand tracking. It uses your webcam to detect hand gestures and turns them into drawing strokes on a live canvas — no mouse, no stylus, just your fingers. The number of fingers you hold up controls the colour, and an open palm erases.

It was built entirely in Python using OpenCV for the video stream and canvas rendering, and cvzone's HandTrackingModule (built on top of MediaPipe) for hand landmark detection. The whole thing runs in real time at webcam frame rate.

How It Works

  • 1 finger up — draws in red
  • 2 fingers up — draws in blue
  • 3 fingers up — draws in green
  • 4 fingers up — draws in yellow
  • Open palm (5 fingers) — erases using the palm centre position
  • C key — clears the entire canvas
  • S key — saves the drawing as a PNG file

The app detects the index finger tip landmark (point 8 from MediaPipe's 21-point hand model) and draws a continuous line between the previous and current frame positions. The canvas layer is blended over the live webcam feed using OpenCV's addWeighted so you can see both your hand and the drawing at the same time.

The Code

The core logic is simple — each frame, check how many fingers are up, pick a colour, and draw from the previous fingertip position to the current one:

finger_count = sum(fingers[1:]) # ignore thumb if finger_count == 1: colour = (0, 0, 255) # Red elif finger_count == 2: colour = (255, 0, 0) # Blue elif finger_count == 3: colour = (0, 255, 0) # Green elif finger_count == 4: colour = (0, 255, 255) # Yellow cv2.line(canvas, (prev_x, prev_y), (x, y), colour, brush_size)

What I Learned

This was my first time working with computer vision and real-time video processing. Getting smooth, continuous lines from noisy hand landmark data was the main challenge — the finger tip position jumps around between frames, so managing the previous position carefully was key to avoiding broken strokes.

  • OpenCV — video capture, frame manipulation, drawing primitives, and image blending
  • MediaPipe / cvzone — hand landmark detection and finger state classification
  • Real-time state management — tracking previous positions across frames to produce smooth continuous lines
  • Computer vision concepts — understanding how hand tracking models work and how to extract useful data from them
